## MCP / Agent / 자동화 관련 소식

- [Windows 11 arm64 VS2026 image generally available](https://github.blog/changelog/2026-08-20-windows-11-arm64-vs2026-image-generally-available) — GitHub Actions에서 Visual Studio 2026이 탑재된 Windows 11 ARM64 이미지가 GA(정식 출시)됐다. 표준 및 대형 GitHub 호스팅 러너 모두에서 사용 가능하며, 워크플로 파일 수정만으로 즉시 적용할 수 있다. ARM64 기반 CI/CD 파이프라인을 구성하거나 전환을 검토하는 팀에게 유용한 업데이트다.
- [Separate GitHub Actions path for GitHub Code Quality](https://github.blog/changelog/2026-08-20-separate-github-actions-path-for-github-code-quality) — GitHub Code Quality 전용 Actions 워크플로 경로가 GA로 출시됐다. 워크플로 실행 이력 및 사용 보고서에서 코드 품질 실행을 일반 Actions 실행과 명확히 구분할 수 있게 됐다. CI/CD 비용 추적과 코드 품질 파이프라인 관리의 가시성이 향상된다.
